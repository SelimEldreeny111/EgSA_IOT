# ESP32 Port

This folder contains the independent ESP32-WROOM 38-pin port of the Arduino
STM32 IoT firmware. The original STM32 Arduino project and the STM32CubeIDE
project are not used or modified by this port.

Open this sketch in Arduino IDE:

- `IoT_Node_ESP32/IoT_Node_ESP32.ino`

Read `IoT_Node_ESP32/ESP32_USER_GUIDE.md` before wiring or uploading. It
contains the mode-specific UART map, power requirements, build profiles, and
the complete bring-up checklist.
